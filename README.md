# PlayRent — прокат игровых консолей и настольных игр

Многостраничный сайт проката: консоли PlayStation, Xbox, Nintendo и настольные игры.
Выполнен на HTML5, CSS3 (переменные, Flexbox, Grid, БЭМ) и небольшом JavaScript, без фреймворков.

**Автор:** Ермаков Арсений

## Как посмотреть

Откройте `index.html` в браузере — сборка не нужна. Для публикации включите GitHub Pages для ветки `main`.

## Страницы

| Страница | Что реализовано |
|---|---|
| `index.html` | шапка, баннер-карусель с акциями, преимущества (доставка за час, проверенное оборудование, без залога), популярные категории, «Новинки», блок «Как это работает», кнопка «Забронировать» |
| `catalog.html` | сетка из 12 карточек, фильтры (платформа, число игроков, цена), сортировка, пагинация по 6 карточек, кнопки «Подробнее» / «Забронировать» |
| `product.html?id=1…12` | фото-галерея, платформа, список игр, комплектация, цена за сутки и неделю, календарь свободных дат, кнопка «Забронировать», похожие позиции, аккордеон с условиями аренды и залогом |
| `booking.html` | три шага: дата и время → доставка и контакты → оплата и напоминание; сводка с расчётом цены; подтверждение брони |
| `contacts.html` | о сервисе, схема зон доставки, таблица сроков, контакты, форма обратной связи с валидацией, FAQ |

Общее: единые шапка и футер, тёмная и светлая тема (запоминается в браузере, учитывает системную), адаптивная вёрстка, мобильное меню.

## Структура

```
index.html, catalog.html, product.html, booking.html, contacts.html
css/style.css    — стили (переменные тем, БЭМ-блоки)
js/main.js       — тема, меню, карусель, каталог, календарь, бронирование, формы
js/products.js   — данные позиций для product.html
images/          — SVG-иллюстрации позиций, слайдов и категорий
```

## Особенности реализации

- **Тема:** переменные в `:root` и `:root[data-theme="dark"]`; атрибут выставляется встроенным скриптом до отрисовки, поэтому нет «мигания».
- **Карусель:** стрелки, точки, свайп, автопрокрутка (останавливается при наведении, фокусе и при `prefers-reduced-motion`); неактивные слайды получают `inert`.
- **Каталог:** фильтрация, сортировка и пагинация на клиенте; ссылки вида `catalog.html?platform=ps` открывают каталог с готовым фильтром.
- **Календарь:** занятые даты условные (генерируются от номера позиции), выбор периода запрещён, если в нём есть занятый день. Выбранные даты передаются в бронирование (`booking.html?id=…&from=…&to=…`).
- **Цена:** недельный тариф за каждые полные 7 суток, остаток — не дороже недели. Доставка бесплатна при сумме от 1500 ₽ и при самовывозе.
- **Бронирование:** валидация каждого шага, маски телефона и карты, проверка дат, предоплата 30% или 100%, напоминание в Telegram / WhatsApp / Viber. Оплата — демонстрационная, данные никуда не отправляются.
- **Доступность:** skip-ссылка, `aria-current`, `aria-live`, `role="alert"` для ошибок, видимый фокус, подписи у всех полей.
